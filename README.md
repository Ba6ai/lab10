## Задание №1 LexicalAnalyzer


### Алгоритм решения

#### Лексический анализвтор - первый этап компилятора. Он разбивает сплошной исходный текст программы на лексемы и заменяет их числовыми кодами токенов.
#### 1) Сначала убирается мусор (пробелы и отступы) и проверяется текущий символ.
#### 2) Запоминаются координаты
#### 3) Конструкция switch-case с распознаванием чисел, букв, различных знаков.
#### 3.1.1) Распознавание чисел (0-9). В цикле while считываются цифры одна за другой. Каждая следующая цифра добавляется к текущему числу формулой nmb_int = 10 * nmb_int + digit;
#### 3.1.2) Есть защита от переполнения. Integer ограничен 16 битами. Перед добавлением цифры, if проверяет чтобы число не вышло за предел. Если вышло - то ошибка 203 и сброс значения до 0.
#### 3.2) Распознавание строчных и заглавных букв. Когда лексёр видит букву или знак подчёркивания, он в цикле собирает буквы и цифры в одну строку name.
#### 4) Двухуровневый поиск по таблице KeyTable.Kw - используется таблица для оптимизации. Таблица организована в виде словарей, сгруппированных по длине слова. Сначала определяется длина идентификатора, затем выполняется поиск только в соответствующем словаре. если слово найдено, возвращает код ключевого слова, иначе оно считается идентификатором.
#### 4.1) Берётся длинна слов len = name.Legth
#### 4.2) Ищется внутренний словарь именно для такой длинны (Kw.TryGetValue(len, out var subDictionary). Если слово длинной 3 (например "var"), то смотрит только в словарь KeyWords.cs
#### 4.3) Итог- если слово найдено в словаре, лексёр понимает что это ключевое слово и возвращает его личный код.
#### 5) Распознавание символов и составных знаков. Некоторые знаки состоят из одного символа (например ; или :), а некоторые из двух (например "<="). Лексёр заглядывает на один символ вперёд. Например : и ; имеют разные коды: colon = 5, assign = 51.
#### 6) Если встретит неизвестный символ, лексёр пропустит его и вернёт код "0".



## Задание №2 SyntaxisAnalyzer с нейтрализацией ошибок


### Алгоритм решения

#### Синтаксический анализатор проверяет, соответствует ли последовательность токенов грамматике языка Паскаль. В работе используется метод рекурсивного спуска. Для каждой основной конструкции программы создан отдельный метод. Анализ начинается с метода Parse(), который запускает разбор программы.
#### Основные методы синтаксического анализва: Parse() -> Program -> VarBlock -> VariableDeclaration -> TypeDeclaration -> RecordType.      Program -> CompoundStatement -> Statement -> AssigmentStatement -> Dessignator.    Statement -> WithStatement.      Statement -> CompoundStatement

#### Program проверяет общую структуру программы: program, имя программы, ;, раздел переменных, составной оператор и .
#### VarBlock обрабатывает раздел var, a VariableDeclaration - отдельное объявление переменных.
#### Метод TypeDeclaration определяет тип переменной. Для записи используется RecordType, где разбираются её поля.
#### CompoudStatement разбирает составной оператор begin ... end.
#### Метод Statement определяет тип текущего оператора: begin - составной оператор    with - оператор присоединения   ident - оператор присваивания.
#### AssigmentStatement разбирает присваивание вида a := 10;
#### Dessignator позволяет использовать не только простые переменные, но и поля записей: student.age := 20;
#### WithStatement student 
```
with student do
begin
    id := 5;
end;
```
