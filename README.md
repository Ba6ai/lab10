Лексический анализатор - первый этап компилятора. Проверяет правила паскаля (делает парсер). Задача - разбить сплошной текст на слова (токены) и заменить их на числовые коды, с которыми ПК проще работать.
Строка a := 10; превратиться в 2(идентификатор), 51(присваивание), 15(число), 14(тчк с зап)
Для вызова нового слова используется NextSym()

1) В самом начале пропускается мусор(пробелы и отступы) - while (InputOutput.Ch == ' ' || InputOutput.Ch == '\t' || InputOutput.Ch == '\r' || InputOutput.Ch == '\n')

2) После запоминаются координаты (LineNumber, CharNumber), для того чтобы знать где мы сейчас находимся.

3) Далее конструкция switch-case с распознавание чисел, букв, различных знаков
3.1) Распознавание чисел (0 - 9) case >= '0' and <= '9':
	В цикле while считываются цифры одна за другой. Каждую новую строку добавляем к 	результату формулой nmb_int = 10 * nmb_int + digit (было 1, умноили на 10, прибавили 	2 = получили 12)
	Присутствует защита от дурака - Integer ограничен 16 битами (32767 символов). Перед 
	добавление if проверяет чтобы число не вышло за предел. Если вышло то ошибка 203 и 
	сбрасывает значение до 0.
3.2) Распознавание Слов (case >= 'a' and <= 'z':) (case >= 'A' and <= 'Z':) (case '_':)
	Когда лексёр видит букву или знак подчёркивания, он в цикле собирвает буквы и цифры 	в одну строку name.
	Далее просиходит Двухуровневый поиск по таблице KeyTable.Kw:
	1) Берётся длинна слова len = name.Length
	2) Ищется внутренний словарь именно для такой длинны (Kw.TryGetValue(len, out var 
	subDictionary). Если слово длинной 3(например, "var"), мы смотрим только в 	словарь(KeyWords.cs)
	для трёхбуквенных слов. Экономия времени процессора.
	3) Итог - если слово найдено с словаре (например 'record или 'with'), лексёр 	понимает, что это ключевое слово языка и возвращает его личный код(recordsy, 	withsy).
	Если слова нет в словаре(например age), лексёр понимет что это просто придуманное 	имя и возвращает обычный код ident (2), а само имя созраняет в addrName.
3.3) Распознавание символов и составных знаков (:= <= .) case ':'
	Некоторые знаки состоят из одного символа (например: ; или ,), а некоторые из двух( например >=). Лексёр заглядывет на один символ вперёд. если после : идёт = , тоон возвращает код присваивания assign(51). Если нет - оставляет код двоеточия colon(5).
